## Professional Approach

My security work is grounded in a repeatable process:

1. Understand the reported issue.
2. Identify unusual or suspicious behavior.
3. Review the evidence available within my authorized access.
4. Determine whether the issue can be safely resolved or requires escalation.
5. Take appropriate containment or remediation actions within my role.
6. Document observations and actions clearly.
7. Escalate security incidents when additional investigation is required.

I focus on accurate investigation and documentation rather than overstating conclusions that are not supported by available evidence.
